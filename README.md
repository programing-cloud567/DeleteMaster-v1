# DeleteMaster v1

Утилита принудительного удаления для Windows 10/11 x64. Работает по принципу лестницы движков: если объект не удаляется обычным способом, включается следующий движок, и так до победного или до перезагрузки.

Автор: **АВТОР** *(замени на своё имя)*

---

## Возможности

- удаление файлов, каталогов и деревьев любой вложенности;
- снятие атрибутов, смена владельца, перезапись DACL, NULL DACL;
- поиск держателей дескрипторов (Restart Manager + таблица дескрипторов ядра);
- завершение дерева процессов-держателей с подъёмом до корня;
- заморозка процессов перед удалением;
- удаление через `FILE_FLAG_DELETE_ON_CLOSE` и `\\?\GLOBALROOT\Device\...`;
- удаление служб, чьи файлы лежат в целевой папке;
- стейджинг: перенос в `$DeleteMaster.Stage` под случайным base64-именем, обнуление и стирание;
- работа с точками монтирования, симлинками и облачными плейсхолдерами;
- отложенное удаление при загрузке + задача SYSTEM, которая добивает остатки после ребута;
- принудительная перезагрузка, если иначе удалить нельзя;
- журнал каждой операции в `logs\`.

## Движки

| Стадия | Модуль | Назначение |
|---|---|---|
| 10 | Basic | базовое удаление, атрибуты, рекурсия |
| 15 | Scan | разведка: атрибуты, держатели, размер |
| 19 | Freeze | заморозка дерева процессов и удаление |
| 20 | Kill | поиск и завершение держателей |
| 25 | Service | удаление/остановка служб, связанных с объектом |
| 30 | Privilege | SeDebug/SeRestore/SeBackup, backup intent |
| 40 | Acl | владелец, DACL, метка целостности |
| 41 | NullDacl | NULL DACL — максимум прав |
| 50 | Native | NtCreateFile + FileDispositionInformationEx |
| 52 | DeleteOnClose | удаление при закрытии дескриптора |
| 54 | GlobalRoot | удаление по device-пути |
| 60 | Streams | альтернативные потоки NTFS, жёсткие ссылки |
| 65 | Staging | перенос в стейдж, обнуление, стирание |
| 70 | Reparse | junction, симлинки, облачные плейсхолдеры |
| 80 | Reboot | очередь удаления при загрузке |
| 93 | Squat | захват имени заглушкой (`/squat`) |
| 90 | Verify | проверка результата, в т.ч. остатков в стейдже |

Хост (`DeleteMaster.exe`) загружает эти модули из папки `engines` через `LoadLibrary` и вызывает единый интерфейс `DmGetInfo` / `DmProbe` / `DmExecute`.

## Требования

- Windows 10/11 x64;
- права администратора — манифест `requireAdministrator`, без UAC программа не запускается.

## Запуск

```
DeleteMaster.exe <путь> [ключи]
```

Без аргументов открывается интерактивный режим: вставь путь или перетащи объект в окно.

Ключи:

```
/nokill       не завершать процессы-держатели
/noacl        не менять владельца и DACL
/noreboot     не планировать удаление при перезагрузке
/norebootnow  не перезагружать автоматически
/norecursive  не заходить в подкаталоги
/nostreams    не трогать альтернативные потоки
/nostaging    отключить стейджинг-удаление
/squat        захватить имя заглушкой после удаления
/dry          пробный прогон без изменений
/quiet        без вывода в консоль
/pause        ждать Enter перед закрытием
/timeout:N    таймаут завершения процесса, мс
/retries:N    число повторов удаления
```

Пример:

```
DeleteMaster.exe "C:\Games\BrokenFolder" /pause
```

## Контекстное меню

`install.bat` — копирует программу в `%LOCALAPPDATA%\Programs\DeleteMaster` и добавляет пункт «Удалить (DeleteMaster)» в меню файлов и папок (HKCU, права администратора не нужны). В Windows 11 пункт находится в «Показать дополнительные параметры».

`uninstall.bat` — убирает пункт и удаляет установленную копию.

## Сборка из исходников

Нужен Visual Studio (MSVC x64):

```
source\build.bat
```

Скрипт сам находит `vcvars64.bat`, собирает иконку, 17 DLL-движков и хост. Результат: `build\bin\DeleteMaster.exe` + `build\bin\engines\*.dll`.

Альтернатива — CMake:

```
cmake -G Ninja -B build
cmake --build build
```

## Важно

- удаление **безвозвратное**, в корзину ничего не попадает;
- программа завершает процессы и удаляет службы — это может привести к потере несохранённых данных;
- при необходимости машина перезагружается без дополнительных вопросов;
- не запускай по системным каталогам и по собственной папке с программой;
- используй на свой риск, автор не несёт ответственности за последствия.
